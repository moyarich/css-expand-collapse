# Interactive examples

Try the [online playground](https://moyarich.github.io/css-expand-collapse/) to expand CSS shorthands, collapse compatible longhands and experiment with the public API.

- [API examples](APIPlayground/) demonstrate individual library functions with editable source.
- [CSS converter examples](CSSConverter/) demonstrate shorthand expansion and computed-style collapse.

For installation and usage, see the [package README](../README.md). To add or maintain examples, see [CONTRIBUTING.md](CONTRIBUTING.md).
