# Developer documentation

Repository setup, workspace commands, architecture notes and the workflow for extending CSS shorthand support are organized into focused pages below.

- [Development](./01-development/page.mdx) — Install dependencies, run the playground, and validate workspaces.
- [Package README and packaging](./02-package-readme/page.mdx) — Maintain the canonical package README and synchronize it for npm packages.
- [Versioning and releases](./03-releases/page.mdx) — Prepare package-qualified tags, dry-run versioning and publish to registries.
- [Playground deployment](./04-playground/page.mdx) — Develop and deploy the React and Vite playground.
- [Runtime and registry architecture](./05-architecture/page.mdx) — Runtime-neutral CSS transformations and shorthand registry design.
- [Adding CSS shorthands](./06-shorthands/page.mdx) — Implement a shorthand module, regenerate the registry and add tests.

The repository-root [README.md](../README.md) is the canonical source for user-facing package installation and API documentation.
